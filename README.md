# Portfolio S-C. Turquety

React, Vite, TypeScript, GSAP + ScrollTrigger, D3 (hiérarchie, échelles), SVG. 100 % statique.

## Développement
    npm install
    npm run dev      # http://localhost:5173
    npm run build    # sortie dans dist/

## Déploiement GitHub Pages
1. Pousser ce dossier à la racine du dépôt (branche main).
2. Réglages du dépôt, Pages, Source : GitHub Actions.
3. Le workflow .github/workflows/deploy.yml construit et publie automatiquement.

## Contenu
Toutes les données sont dans src/data.ts (issues du CV source). Aucun chiffre n'est ajouté.
